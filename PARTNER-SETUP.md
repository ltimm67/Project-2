# Partner Setup

## What is included

- `app.py` — the Streamlit application
- `prices.csv` — the local price data used by the application
- `requirements.txt` — required Python packages
- `INSTALL-AND-RUN.bat` — one-step Windows installer and launcher
- Project documentation and the supplied Markdown files

## Run on Windows

1. Extract the shared ZIP to a writable folder, such as `Documents`.
2. Install [Python 3](https://www.python.org/downloads/) if it is not already installed. During installation, select **Add Python to PATH**.
3. Double-click `project-2-investment-management-app\INSTALL-AND-RUN.bat`.
4. On the first run, wait while it creates a local virtual environment and installs `streamlit` and `pandas`.
5. Open the local URL displayed in the command window, usually `http://localhost:8501`.

The application and data remain local to the partner's computer. The command window must remain open while the app is running; press `Ctrl+C` in that window to stop it.
